# Domain Docs

This is a single-context repository.

Before exploring, read:

- `CONTEXT.md` at the repository root.
- Relevant ADRs under `docs/adr/`.

Use the glossary and evidence boundaries from `CONTEXT.md` when naming domain
concepts in issues, tests, documentation, and implementation notes. In
particular, preserve the distinction between development folds, final test,
one-step forecasts, fixed-origin projections, prediction intervals, and
exploratory anomaly signals.
